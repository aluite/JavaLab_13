# Лабораторная работа №13 — Платформа JavaFX

## Требования
- JDK 17
- Apache Maven 3.8+
- JavaFX 21.0.1 (подключается Maven автоматически)

## Запуск
Откройте терминал в корне проекта, где находится `pom.xml`, и выполните:

```bash
java -version
mvn -version
mvn clean javafx:run
```

Maven должен использовать JDK 17. Приложение запускается без FXML: интерфейс создаётся в классе `ru.guu.App`.

## Возможности
- Ввод двух чисел в `TextField`.
- Вычисление суммы по кнопке.
- Проверка пустого, некорректного и бесконечного ввода.
- Кнопка «Очистить»: очищает оба поля и результат, возвращает фокус в первое поле.
- Повторный расчёт после очистки.

Десятичный разделитель — точка: `2.5`. Допустимы отрицательные числа.
